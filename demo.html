Nikos Messenger - Call System Demo

System Status: All components created successfully!

Features

  • 1:1 Audio/Video Calls
  • Group Calls (up to 32 participants)
  • Call History with Status
  • Missed Call Indicators
  • Date & Time Display
  • Delete Calls (individual or all)
  • Secure API Endpoints

Call Status Types

  • Accepted ANGENOMMEN - Call was answered
  • Missed VERPASST - Call was not answered
  • Rejected ABGELEHNT - Call was declined
  • Cancelled ABGEBROCHEN - Call cancelled before answer

Setup Required:
  1. Import database: mysql -u root -p < database.sql
  2. Configure database in config.php
  3. Install Node.js dependencies: npm install
  4. Start Socket.IO server: npm start
  5. Access via web server (Apache/Nginx with PHP)

Technical Stack

  • PHP - Backend API
  • MySQL - Database
  • Node.js - Socket.IO Server
  • WebRTC - Real-time Communication
  • Socket.IO - WebSocket Communication

Quick Start

Start the Socket.IO server:

cd /path/to/nikos_messenger
npm install
npm start

The server will start on port 3000. Check health:

curl http://localhost:3000/health

Files Created

  • webrtc-calls.js - WebRTC client
